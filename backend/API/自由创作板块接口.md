# 自由创作板块接口

# 获取自由创作初始工作区

**功能**：用户进入自由创作模块，初始化创作空间（新建/加载草稿）。

- **路径**：`GET /api/composition/init`

- **请求方式**：`GET`

- **参数**：

响应示例：

```JSON
{
  "code": 200,
  "data": {
    "composition_id": 1,       // 新建/加载的创作ID（关联`composition.id`）
    "ticks_per_beat": 480,      // 每拍刻度数（默认480，可从`string_profile`扩展）
    "edit_status": "EDITING",   // 编辑状态（EDITING/DRAFT/LOCKED）
    "notes": []                 // 初始音符列表（或加载草稿音符，含`note_id`、`string_part_id`等）
  }
}
```

# 拖拽音符（创建/更新/删除）

**功能**：用户拖拽音符，后端创建/更新/删除`composition_note`记录（人工音符标记为`ai_completion_no=NULL`）。

- **路径**：`POST /api/composition/note`

- **请求方式**：`POST`

- **参数**（JSON Body）：

响应示例：

```JSON
{
  "code": 200,
  "data": { "note_id": 1, "msg": "音符创建成功" }
}
```



# 请求AI补全乐段

**功能**：用户触发“智能补全”，后端生成补全批次（`ai_completion`表），并返回建议音符。

- **路径**：`POST /api/composition/ai-completion`

- **请求方式**：`POST`

- **参数**（JSON Body）：

响应示例：

```JSON
{
  "code": 200,
  "data": {
    "completion_id": 1, // ai_completion.id（关联`composition_id`+`batch_no`）
    "suggested_notes": [
      { "string_part_id": 3, "start_tick": 960, "duration_tick": 480, "velocity": 85, "note_state": "PROPOSED" },
      // ... 其他AI建议音符
    ]
  }
}
```

# 接受/拒绝AI补全结果

**功能**：用户对AI补全的音符进行“接受”或“拒绝”，更新音符状态和补全批次状态。

- **路径**：`PUT /api/composition/ai-completion/{completion_id}/decision`

- **请求方式**：`PUT`

- **参数**（路径参数\+JSON Body）：

响应示例：

```JSON
{
  "code": 200,
  "data": { "msg": "已接受补全结果，音符状态更新为ACTIVE" }
}
```



# 确认创作完成，编译乐谱为控制指令

**功能**：用户点击“完成创作”，后端锁定乐谱（`composition.edit_status='LOCKED'`），并编译音符为机器人指令（存储到`digital_asset`表）。

- **路径**：`POST /api/composition/complete`

- **请求方式**：`POST`

- **参数**（JSON Body）：

响应示例：

```JSON
{
  "code": 200,
  "data": {
    "composition_id": 1,
    "edit_status": "LOCKED",
    "command_asset_id": 1, // digital_asset.id（编译后的指令资源）
    "msg": "乐谱已锁定，指令编译完成"
  }
}
```



# 发起机器人演奏任务

**功能**：根据编译后的指令，创建`performance_run`记录，触发硬件通讯。

- **路径**：`POST /api/performance/run`

- **请求方式**：`POST`

- **参数**（JSON Body）：

响应示例：

```JSON
{
  "code": 200,
  "data": {
    "run_id": 1, // performance_run.id
    "run_status": "QUEUED", // 初始排队状态（QUEUED/SENDING/PLAYING/SUCCESS/FAILED/CANCELLED）
    "msg": "机器人演奏任务已创建，等待执行"
  }
}
```



# 查询演奏任务状态

**功能**：前端轮询或推送，获取机器人演奏的实时状态。

- **路径**：`GET /api/performance/run/{run_id}`

- **请求方式**：`GET`

- **参数**（路径参数）：

响应示例：

```JSON
{
  "code": 200,
  "data": {
    "run_id": 1,
    "run_status": "PLAYING",
    "started_at": "2024-01-01T10:00:00.123Z",
    "ended_at": null,
    "actual_duration_ms": null
  }
}
```

# 演奏反馈（评分、评论、感受词）

**功能**：演奏结束后，用户提交反馈，后端记录`performance_feedback`和`feedback_descriptor`（感受词）。

- **路径**：`POST /api/performance/feedback`

- **请求方式**：`POST`

- **参数**（JSON Body）：

响应示例：

```JSON
{
  "code": 200,
  "data": { "feedback_id": 1, "msg": "反馈提交成功" }
}
```
