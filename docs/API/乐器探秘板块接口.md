# 乐器探秘板块接口

# 立体结构讲解

## 首页信息

功能：返回“乐器探秘”板块的子入口（立体结构讲解、历史讲解），及模块分类、功能点说明。

路径：`GET /api/instrument-explore/home`

```JSON
{
  "code": 200,
  "data": {
    "modules": [
      { "name": "乐器立体结构讲解", "type": "STRUCTURE", "desc": "3D模型+部件讲解" },
      { "name": "乐器历史讲解", "type": "HISTORY", "desc": "时间轴+文化故事" }
    ]
  }
}
```

## 获取古筝整体结构（3D？）

功能：返回古筝整体3D模型资源（如 `digital_asset`表的多媒体信息）、关键部位（琴弦、琴码、面板等，关联 `history_entry`）。

路径：`GET /api/instrument-explore/structure/overview`

```JSON
{
  "code": 200,
  "data": {
    "model_asset": { "id": 1, "url": "https://xxx.com/3d/model.glb", "type": "3D_MODEL" },
    "key_parts": [
      { "part_id": 1, "name": "琴弦", "desc": "古筝发声核心部件", "image_url": "..." },
      { "part_id": 2, "name": "琴码", "desc": "支撑琴弦并传递振动", "image_url": "..." },
      // ... 其他部位
    ]
  }
}
```

## 获取部件详情介绍

功能：点击“查看详情”后，返回部件的详细作用、位置、与演奏的关系（关联 `history_entry.detail`或扩展字段）。

路径：`GET /api/instrument-explore/structure/part-detail`

参数：`part_id`

```JSON
{
  "code": 200,
  "data": {
    "part_id": 1,
    "name": "琴弦",
    "function": "振动发声，决定音高",
    "position": "纵向排列于面板，通过岳山固定",
    "play_relation": "按弦位置（吟猱绰注）改变音色，弦的松紧度决定音准",
    "images": [/* 局部示意图、放大图 */]
  }
}
```

## 试听？

功能：用户点击某根弦（或弦号），返回弦的高亮信息、音名/音区、试听音频（关联 `digital_asset`表的音频资源）。

路径：`GET /api/instrument-explore/structure/string-highlight`

参数：`string_no`（弦号，如1\~21）、`action`（highlight/play）

```JSON
{
  "code": 200,
  "data": {
    "string_no": 5,
    "highlight": true,
    "pitch": "G4",
    "region": "中音区",
    "audio_url": "https://xxx.com/audio/string_5.mp3"
  }
}
```

```JSON
{
  "code": 200,
  "data": { "action": "play", "audio_url": "https://xxx.com/audio/string_5.mp3" }
}
```

# 历史讲解

## 获取古筝历史时间轴

功能：返回古筝发展的历史阶段（古代起源、发展演变、现代传播），关联 `history_entry`表的历史分类。

路径：`GET /api/instrument-explore/history/timeline`

```JSON
{
  "code": 200,
  "data": {
    "stages": [
      { "stage_id": 1, "title": "先秦起源", "desc": "古筝雏形源于秦地...", "time": "公元前221年前" },
      { "stage_id": 2, "title": "唐宋发展", "desc": "形制定型，成为宫廷雅乐...", "time": "618-1279年" },
      // ... 其他阶段
    ]
  }
}
```

## 获取历史阶段的代表曲目/故事

功能：点击历史阶段的“经典曲目/文化故事”，返回曲目列表（关联 `song`表）及背景说明。

路径：`GET /api/instrument-explore/history/stage-songs`

参数：`stage_id`

```JSON
{
  "code": 200,
  "data": {
    "stage_id": 1,
    "songs": [
      { "song_id": 1, "name": "《高山流水》", "bg": "古筝名曲，喻知音难觅..." },
      { "song_id": 2, "name": "《渔舟唱晚》", "bg": "描绘渔村晚景..." }
    ]
  }
}
```

## 点歌联动（历史讲解→点歌模块）

功能：从历史讲解的曲目卡片点击“听一听”，跳转到点歌模块并定位曲目（需记录交互日志 `interaction_event`，并更新点歌候选）。

路径：`POST /api/instrument-explore/history/song-link`

参数：`song_id`（历史讲解中的曲目ID）、`session_id`（用户会话ID）

```JSON
{
  "code": 200,
  "data": { "target_module": "SONGBOOK", "target_song_id": 1, "msg": "已跳转至点歌模块" }
}
```
